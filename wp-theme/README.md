# Тема WordPress «SAO Aincrad»

Курсова робота: **розробка корпоративного сайту на WordPress зі створенням власної теми**.
Тема написана з нуля (без готових тем, конструкторів і плагінів) на основі статичного сайту з кореня репозиторію.

## Структура теми

```
sao-aincrad/
├── style.css            заголовок теми (назва, автор, версія) — без нього WordPress не бачить тему
├── functions.php        налаштування теми, підключення CSS/JS, SEO-мітки
├── header.php           <head>, верхня панель, меню, перемикач теми
├── footer.php           підвал
├── front-page.php       головна: hero, цифри, Айнкрад, механіка, історія, персонажі, гільдії, новини
├── index.php            сторінка «Новини» (список записів) і запасний шаблон
├── single.php           окрема новина / персонаж / гільдія
├── page.php             звичайна сторінка («Про проєкт»)
├── page-contacts.php    шаблон сторінки «Контакти» з формою
├── archive.php          /characters/, /guilds/, мітки новин
├── search.php, searchform.php, 404.php, comments.php, sidebar.php
├── template-parts/      картки персонажа і гільдії, пункт новини, форма
├── inc/
│   ├── post-types.php   власні типи записів «Персонажі», «Гільдії», «Заявки» + поля
│   ├── customizer.php   налаштування в «Вигляд → Налаштувати → Тема SAO Aincrad»
│   ├── contact-form.php REST API /wp-json/sao/v1/contact — збереження заявок
│   ├── template-tags.php допоміжні функції, SVG сонця/місяця і неба
│   └── demo-content.php  демо-вміст, що створюється при активації теми
└── assets/
    ├── css/main.css     усі стилі, світла й темна тема
    ├── js/theme.js      перемикач теми, меню, анімації
    ├── js/contact.js    перевірка й відправка форми
    └── images/, icons/
```

## Що вміє тема (чим вона «корпоративна»)

| Можливість WordPress | Де в темі |
|---|---|
| Меню (`register_nav_menus`) | «Вигляд → Меню», 2 області: головне і в підвалі |
| Власні типи записів (CPT) | «Персонажі» (команда), «Гільдії» (партнери), «Заявки» |
| Мета-поля | блок «Дані SAO» праворуч у редакторі |
| Customizer | тексти головного екрана, посилання, email |
| Блог | «Новини» — звичайні записи з мітками («Поверх 75») |
| Віджети | «Бічна панель новин» |
| REST API | форма відправляє дані без перезавантаження |
| Логотип, іконка сайту | «Налаштувати → Ідентичність сайту» |
| Ієрархія шаблонів | front-page → index, single, page, archive, search, 404 |

## Перемикач теми «сонце ↔ місяць»

1. **Скрипт у `<head>`** (`functions.php`, `sao_theme_boot_script`) ще до відмальовки читає збережену тему з `localStorage`
   і ставить `<html data-theme="dark|light">` — тому сторінка не «блимає».
2. **Кнопка** (`sao_theme_toggle()` у `inc/template-tags.php`) — один SVG, де одночасно намальовані і сонце (ядро + 8 «клинків»-променів),
   і місяць (коло з «вкушеним» краєм через `mask` + кратери + зірки).
3. **CSS** (`main.css`, розділ 4) залежно від `data-theme` ховає одну іконку: вона обертається на 140° і зменшується,
   а інша «вилітає» з пружинним ефектом (`cubic-bezier(.34,1.56,.64,1)`). Промені сонця повільно обертаються, зірки мерехтять.
   При наведенні — помаранчеве світіння і пунктирне кільце, як у меню SAO.
4. **JavaScript** (`theme.js`) при кліку викликає `document.startViewTransition()`: браузер робить «знімок» старої сторінки,
   а нова тема розливається **колом від кнопки** на весь екран (анімація `clip-path: circle()`).
   У браузерах без цього API (Firefox) кольори просто плавно змінюються через `transition`.
5. **Небо в шапці** теж реагує: сонце «заходить» униз, місяць «сходить», вночі з'являються зорі, падаюча зірка і вогники в Айнкраді.

Усі анімації вимикаються, якщо в системі ввімкнено «Зменшити рух» (`prefers-reduced-motion`).

## Демо-вміст

При активації теми (`after_switch_theme`) автоматично створюються: сторінки «Головна», «Новини», «Про проєкт», «Контакти»,
4 персонажі, 4 гільдії, 9 новин і головне меню; головна сторінка стає статичною. Повторна активація нічого не дублює.

## Локальний запуск (без XAMPP)

Потрібен лише Node.js. У папці `wp-theme`:

```
npx @wp-playground/cli@latest server --mount=./sao-aincrad:/wordpress/wp-content/themes/sao-aincrad --blueprint=./blueprint.json
```

Відкрити адресу з консолі (зазвичай http://127.0.0.1:9400), адмінка — `/wp-admin` (логін вже виконано).
Дані зберігаються лише до зупинки сервера.
